## Primary Training Data

The TCN-Attention-BiLSTM model is trained **exclusively** on NASA HTTP 1995 data:
- Raw logs: 3.46M records (Jul + Aug 1995)
- Windows: 81,381 samples (56,906 train / 12,147 val / 12,148 test)
- Shape: (samples, 60, 19) float16
- Target: `target_next_congestion_score` (proxy congestion score, 15-minute horizon)

## Usage Notes

- The real traces from Zenodo (`Data/real/`) have **different schemas** than the synthetic files and are NOT used for the primary NASA HTTP 1995 training pipeline. They are available for future multi-source research.
- The synthetic files in `Data/` are used by `src/data/external_log_downloader.py` as fallback data sources, but are clearly labeled as synthetic.
- The primary model (TCN-Attention-BiLSTM) is trained ONLY on NASA HTTP 1995 data. The synthetic files do not affect the main results.
